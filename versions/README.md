# Jet Elite - Versiones y Respaldos Históricos

Esta carpeta contiene los respaldos de las iteraciones anteriores para que nunca se pierda ningún componente ni código:

- `v1-charter-initial/`: Primera versión enfocada en cotizador chárter en 4 pasos, estimador FBO rápido y trust signals.
- `v2-quiet-luxury-awwwards/`: Versión de arte Awwwards Quiet Luxury con 4 idiomas (ES, EN, FR, PT), Bento Grid y modelo Felton Aviation.
- `master/`: Fusión maestra con lo mejor de ambas versiones (Flujo completo de cotización + Bento Grid + Calculadora ROI + Simulador de Alcance + Empty Legs + IA Jet Concierge + 4 Idiomas).
